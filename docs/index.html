Features

📡 Point Cloud Types

  • 3D points (x, y, z, intensity)
  • ASPRS classification codes
  • Bounding box computation
  • Centroid calculation
  • Dynamic point collection

🏗️ Ground Filtering

  • Single-pass minimum-Z per grid cell, with a configurable cell size and height threshold
  • That pass alone is not a progressive morphological filter (no opening, no window progression, no slope, no iteration)
  • Progressive morphological filter (Zhang et al. 2003) with growing windows and a slope-driven threshold

✂️ Thinning

  • The random method keeps a fraction at an even index stride
  • It draws no random numbers, so one cloud always thins to the same points
  • Voxel decimation keeps the first point in each voxel
  • Configurable voxel size
  • A kept point carries its classification through

🌳 Spatial Indexing

  • Octree construction
  • Radius queries
  • Configurable leaf size
  • Depth-limited subdivision
  • 3D bounding box tracking

💾 LAS Files

  • Reads point record formats 0 to 3
  • Writes LAS 1.2 format 0 at a 1 mm scale
  • Header parsing over any reader
  • Class codes the enum does not name keep their value
  • Per-point surface normals and outlier removal

🗺️ Gridding

  • Inverse distance weighting over the cloud bounds
  • Inverse distance weighting over a caller-chosen window, for tiles
  • Ordinary kriging with a fitted spherical variogram
  • Esri ASCII grid output with values on the nodes

📈 Geostatistics

  • Empirical variograms
  • Spherical, exponential, and gaussian models
  • Moran's I spatial autocorrelation
  • Getis-Ord Gi* hot-spot scores

⌨️ Command Line

  • info prints header, bounds, and class counts
  • ground-classify and pmf label ground points
  • thin, filter-class, outlier-removal reduce a cloud
  • interpolate-to-grid and variogram produce the surface
  • demo writes a synthetic terrain to try on

Quick Start

use nubis_core::{Point3, PointCloud, ground_filter_simple, Octree};

let mut cloud = PointCloud::from_points(points);
ground_filter_simple(&mut cloud, 2.0, 0.5);

let tree = Octree::build(cloud.points(), 64);
let nearby = tree.query_radius(cloud.points(), &query, 5.0);
